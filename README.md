# E-Commerce Business Intelligence & Customer Analytics

An end-to-end data analytics project exploring e-commerce business performance using Python, SQL, and Power BI.

## Project Overview

This project uses the Brazilian E-Commerce Public Dataset by Olist to investigate business performance, customer behaviour, product sales, payments, and delivery operations.

The goal is to transform raw e-commerce data into meaningful insights that can support business decision-making.

## Objectives

- Analyze overall sales and revenue performance.
- Understand customer purchasing behaviour.
- Identify top-performing products and categories.
- Evaluate payment methods and order patterns.
- Investigate delivery performance and customer satisfaction.
- Build interactive business intelligence dashboards.

## Technology Stack

- **Python:** Pandas, NumPy, Matplotlib, Seaborn
- **SQL:** MariaDB / MySQL
- **Business Intelligence:** Microsoft Power BI
- **Development:** Jupyter Notebook, VS Code, Git and GitHub

## Project Progress

### Phase 1: Data Understanding — Completed

- Loaded and inspected the eight core datasets.
- Examined dataset dimensions, columns and data types.
- Investigated missing values and duplicate records.
- Explored financial values, product measurements and category distributions.

### Phase 2: Data Cleaning and Preparation — Completed

- Standardized column names.
- Converted date columns to appropriate datetime types.
- Standardized postal code prefixes.
- Investigated missing and zero values.
